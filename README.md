## 🏭 What I work on

- 🤖 **Robotics integration**: collaborative robots (cobots) and autonomous mobile robots (AMR) in production cells
- 🧩 **Digital twin & simulation**: virtual commissioning, robot path/waypoint validation, collision checking, cycle-time optimisation
- 🔌 **Industrial connectivity**: PLC networks (FL-net), Fanuc CNC, bridging machines to monitoring and traceability systems
- 👁️ **Machine vision & AI cameras**: vision inspection tools and software for quality checks on the line
- 📊 **Monitoring & traceability**: real-time equipment status and part/process traceability for quality gates
